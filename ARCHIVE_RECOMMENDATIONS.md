## 📋 Archiving Checklist

When archiving a repository, follow this process:

### Pre-Archive (1 week before)
1. ✅ Create/update README documenting why archived
2. ✅ Close any open issues with explanation
3. ✅ Migrate any valuable PRs or discussions
4. ✅ Download full repo backup if needed
5. ✅ Update any external documentation/links
6. ✅ Notify any team members

### Archive Process
1. ✅ Go to repository Settings
2. ✅ Scroll down to "Danger Zone"
3. ✅ Click "Archive this repository"
4. ✅ Confirm action
5. ✅ Update issue tracker/project board

### Post-Archive
1. ✅ Document in project wiki/documentation
2. ✅ Update team communication
3. ✅ Remove from any navigation/listings
4. ✅ Monitor for any external links that break
